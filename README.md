- Inhalt: 499 Dateien, ohne externe Medienwerkzeuge.

ZIP-Integrität und Prüfsumme wurden nach der Erstellung erneut geprüft. Die Anwendung enthält den vollständigen erforderlichen Datenordner und das anonymisierte Handbuch für 9.8.7. Benötigte Python-/Qt-Laufzeitbibliotheken bleiben enthalten und unterliegen ihren eigenen Lizenzen. Externe Medienwerkzeuge werden anhand von `TOOLS_INSTALLIEREN.txt` separat eingerichtet.

## Ablage und Veröffentlichung

ZIP und SHA-256 bleiben auf ausdrücklichen Wunsch ausschließlich lokal unter `artifacts` und werden gemäß bestehender `.gitignore` nicht eingecheckt. Es wird kein GitHub Release angelegt oder veröffentlicht. Der Git-Push aktualisiert die Release-Dokumentation.

Zum Installieren die Prüfsumme prüfen, das ZIP in einen neuen Ordner entpacken und die EXE zusammen mit dem Ordner `Daten` belassen. Eigene Einstellungen und Regeln vor einem Update sichern.

Der aktuelle Quellcode wird separat in `Dragontools-Public` gepflegt. Frühere Release-Hinweise bleiben historisch erhalten.
